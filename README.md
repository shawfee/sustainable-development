# sustainable development

#### 介绍
联合国全体成员国于2015年9月在联合国可持续发展峰会上集体通过了全球2030可持续发展议程，该议程从包括健康、教育.环保、能源、城市化、工业化等17个领域为全球未来十五年发展设定了宏伟目标，即联合国2030全球可持续发展目标，简称SDGs。

#### 目标
SDGS为2030年全球和全人类的经济发展、社会发展与生态环境的可持续性描绘了新蓝图，具有里程碑意义。作为全球第二大经济体和最大的发展中国家，中国在推动SDGS进展、推动构建人类命运共同体方面正扮演着大国的角色。同时，中国在推动实现联合国千年发展目标上为全球做出了巨大贡献，但经济发展面临寻找新动能和结构转型问题，社会发展的包容性和协调性仍待增强，实现碳达峰和碳中和目标面临着快速的工业化和城镇化对能源需求的制约，中国在未来实现可持续发展的道路上面临诸多问题和挑战。
